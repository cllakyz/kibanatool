# Actions

On the **Actions** tab, add link or Discover actions, and paste a sample log into the preview to see the result.
Mark **Show in row** on the ones you also want on the result rows (see
[Action bar and row buttons](/docs/use/action-bar-and-row-buttons)).
Or import the [example settings](/docs/configure/example-actions) under **Export and import** and edit them.

A Discover action opens the data view of the open log, or the one under **Target data view**: a display
name or an index pattern (e.g. `*_log`), looked up in the current space, or an ID. If no data view or more
than one matches the name, the button is greyed out.

Templates are built from [placeholders and conditions](/docs/configure/placeholders-and-conditions).
