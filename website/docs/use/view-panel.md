# View panel

**View** shows fields that hold JSON, XML or form text, such as a request body, as a tree you can search and copy
from, and long or multi-line text, such as console output or a stack trace, as text you can search.

- XML and form text are read as JSON: see [XML and form data](/docs/use/xml-and-form-data).
- Text that is not structured is listed in the [Text view](/docs/use/text-view).
