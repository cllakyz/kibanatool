# First setup

1. [Install kibanatool](/docs/getting-started/install) from the <a href={STORE_URL}>Chrome Web Store</a>.
2. Click the toolbar icon to open the options.
3. Import <a href={exampleSettingsUrl("en")}><code>kibanatool-settings.json</code></a> under **Export and import**
   and edit it. Importing replaces all current settings.
4. **Environments:** change the example address to your Kibana address, e.g. `https://kibana.example.com` or
   `https://example.com/kibana`, and click **Grant access**. Chrome asks for access to that site; the extension runs
   nowhere else. See [Environments](/docs/configure/environments).
5. **Variables:** values that differ per environment, like your admin panel's address. Each row is a
   variable, each column an environment; use them in templates as `{env.name}`. See [Variables](/docs/configure/variables).
6. **Actions:** add link or Discover actions, and paste a sample log into the preview to see the result.
   Mark **Show in row** on the ones you also want on the result rows. See [Actions](/docs/configure/actions).
7. Reload your Kibana tab and open a log.
