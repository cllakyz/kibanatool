# Görüntüle paneli

**Görüntüle**, istek gövdesi gibi JSON, XML ya da form metni tutan alanları içinde arama yapıp kopyalayabileceğiniz
bir ağaç olarak, konsol çıktısı ya da stack trace gibi uzun veya çok satırlı metni de içinde arama yapabileceğiniz
metin olarak gösterir.

- XML ve form metni JSON olarak okunur: bkz. [XML ve form verisi](/docs/use/xml-and-form-data).
- Yapılandırılmış olmayan metin [metin görünümünde](/docs/use/text-view) listelenir.
