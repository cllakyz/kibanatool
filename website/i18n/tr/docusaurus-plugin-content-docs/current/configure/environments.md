# Ortamlar

Ayarlar sayfasının **Ortamlar** sekmesinde Kibana adresinizi ekleyin, örn. `https://kibana.example.com` ya da
`https://example.com/kibana`. Chrome o site için erişim izni ister; eklenti başka hiçbir yerde çalışmaz.

Erişim her adres için, adresi eklediğinizde istenir; bu erişimi istediğiniz zaman `chrome://extensions` sayfasından
kaldırabilirsiniz. Bkz. [Gizlilik ve izinler](/docs/more/privacy-and-permissions).
